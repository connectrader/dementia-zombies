DEMENTIA ZOMBIES (Windows)
==========================

Double-click "Dementia Zombies.exe". The game opens in its own window.
Close the window to quit.

FIRST RUN
- Windows may say "Windows protected your PC" because the app isn't signed.
  Click "More info", then "Run anyway".
- Windows Firewall will ask whether to allow Dementia Zombies on your network.
  Tick "Private networks" and click Allow. This is what lets friends on your
  Wi-Fi or LAN see and join your game.

PLAYING TOGETHER ON A LAN (up to 4 players)
1. Everyone runs Dementia Zombies on the same Wi-Fi or wired network.
2. One person presses C (Co-op) and clicks "Host a game".
3. Everyone else presses C. The host's game shows up in the list within a few
   seconds. Click Join.
   - Not showing up? Type the host's address (shown on the host's Co-op
     screen, e.g. 192.168.1.20) into "Host address" and press Find.
   - No copy of the app? A friend can open http://<host address>:47800 in any
     browser on the network (phones and Macs included) and join from there.

SAVES
- Save slots live in %APPDATA%\Dementia Zombies\saves
- Exported save files go to Documents\Dementia Zombies

NOTES
- Uses Microsoft Edge (built into Windows 10 and 11) to draw the game window.
- Network ports: TCP 47800 for the game, UDP 47801 for finding games.
- A second copy on the same PC uses port 47802 and keeps its own saves.
